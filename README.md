# ♟️ Chess4 Screen Bot

**Chess4 Screen Bot** — профессиональный автономный шахматный экранный ассистент нового поколения. Работает поверх любого браузера (Chess.com, Lichess, Chess24 и др.) и настольных приложений через прозрачный клик-проходимый оверлей.

В отличие от ранних версий (`chess2`, `chess3`), архитектура v4 полностью избавлена от детских болезней (сдвигов сетки на 1 клетку, путаницы пешек со слонами, зависаний пайпов Stockfish) и оснащена продвинутым античит-комплексом кинематики мыши и офлайн голосовыми подсказками.

## 🌟 Ключевые возможности

### 1. 🥷 Stealth & Anti-Cheat Humanization (Человекоподобность)
* **Биомеханическая кинематика мыши** ([`chessvision/mouse.py`](file:///chessvision/mouse.py)):
  * Траектории строятся по кубическим сплайнам Безье с физиологической моделью **минимального рывка (Flash & Hogan Minimum-Jerk)**:
    $$s(t) = 10t^3 - 15t^4 + 6t^5$$
  * Физиологический тремор кисти (микро-джиттер), лёгкие случайные перелёты за пределы целевой точки (overshoot) с последующей доводкой.
  * Точка клика выбирается с гауссовым разбросом внутри клетки, а удержание кнопки мыши варьируется от 45 до 95 мс.
* **Динамический тайм-менеджмент**:
  * В дебюте и при форсированных разменах бот ходит быстро (0.3–0.7 с).
  * В сложных позициях миттельшпиля время обдумывания генерируется по нормальному распределению Гаусса (1.5–3.5 с), имитируя раздумья гроссмейстера.

### 2. 🖱️ Двухрежимный автоход: Перетаскивание (Drag-and-Drop) и 2 клика
* Кнопка **«Тянуть» / «2 клика»** на панели управления:
  * **«Тянуть» (Drag-and-Drop, по умолчанию)**: зажатие фигуры $\to$ плавный пронос с зажатой кнопкой по кривой Безье $\to$ отпускание на целевой клетке. Работает абсолютно на **всех** шахматных сайтах (включая платформы, где отключён click-to-move).
  * **«2 клика» (Click-to-Move)**: клик по фигуре $\to$ естественная пауза $\to$ клик по целевой клетке.

### 3. 🗣️ Офлайн голосовой комментатор ходов (Windows SAPI TTS)
* Модуль [`chessvision/voice.py`](file:///chessvision/voice.py) использует системный речевой движок Windows SAPI через изолированный COM-поток:
  * **0 задержек, 0 внешних библиотек и 0 сетевого трафика** — работает полностью локально без интернета.
  * Автоматически подключает качественный русский голос (**Microsoft Irina Desktop - Russian**).
  * Произносит ходы на правильном шахматном русском языке: *«е четыре»*, *«конь эф три»*, *«короткая рокировка»*, *«слон бьёт дэ семь, шах»*.
  * Авто-очистка очереди: если соперник ходит быстро, диктор сразу произносит актуальный ход, не задерживая партию.

### 4. 🏹 MultiPV: Мультилинейный анализ и режим «Без стрелок»
* Переключатель количества линий в выпадающем списке:
  * 🎧 **«Без стрелок (только голос / окно)»** — режим максимальной скрытности. Оверлей над доской остаётся абсолютно чистым и прозрачным (0 стрелок, 0 рамок), а подсказки идут голосом в наушники или текстом в окне бота.
  * 🟢 **«1 лучшая стрелка»** — зелёная стрелка основного хода (`#00e676`).
  * 🟡 **«2 стрелки»** — зелёная лучшая + золотистая альтернатива (`#ffd600`).
  * 🔵 **«3 стрелки»** — полный спектр (зелёная + золотистая + бирюзовая `#00b0ff`).
* В окне программы отображается строка всех линий (например: `1. c4 (+0.25) | 2. d4 (+0.18)`).

### 5. 🎚️ Регулировка силы движка (Elo / Skill Level)
* Выбор силы игры в интерфейсе:
  * `Max (3500+)` — полная мощь Stockfish 19 Universal.
  * `2500 (GM)` — уровень гроссмейстера.
  * `2100 (Мастер)`
  * `1800 (КМС)`
  * `1500 (Любитель)`
* Управляет параметрами движка `UCI_LimitStrength`, `UCI_Elo` и `Skill Level`, позволяя играть с реалистичной человеческой точностью или тренироваться.

### 6. 🛡️ Стопроцентная точность зрения и авто-привязка
* **Инвариант чётности углов**: алгоритм строго проверяет цвет угловых полей ($a1/h8$ тёмные, $a8/h1$ светлые). Исключены любые сдвиги сетки на 1 клетку.
* **Авто-привязка рамки (`snap_selection`)**: при ручном обведении доски мышкой программа автоматически находит внутренние контрастные линии клеток 8x8 и сама притягивает координаты пиксель-в-пиксель.
* **Поддержка темплейтов Neo и классики**: геометрия силуэта и высота клеток исключают путаницу пешек со слонами и ферзей с королями.
* **Защита от мусора (Placement Sanity Validator)**: проверяется наличие ровно двух королей, расстояние между ними и отсутствие скоплений одинаковых фигур на рядах.

### 7. 🖥️ Мультимониторность и поворот доски
* Полноценная поддержка мультимониторных конфигураций (выбор любого экрана в списке).
* Авто-определение стороны игры: белые и чёрные фигуры определяются автоматически. Фиксация сессии исключает переворот доски посреди эндшпиля.

## ⌨️ Горячие клавиши (Оптимизировано для ноутбуков)

На ноутбуках верхний ряд F1–F12 часто занят системными функциями (яркость, звук) и требует зажатия `Fn`. В **chess4-screen-bot** горячие клавиши назначены на верхний цифровой ряд `Alt + 1..6` и тильду `~` — они нажимаются мгновенно одной левой рукой из любого окна:

| Клавиша на ноутбуке | Классическая клавиша | Действие | Описание |
| :---: | :---: | :--- | :--- |
| **`Alt + 1`** (или **`~`** / **`Alt + Z`**) | `F4` / `F1` | **Пуск / Пауза** | Быстрый старт или остановка слежения. |
| **`Alt + 2`** (или **`Alt + X`**) | `F5` | **Сброс** | Очистка позиции для новой партии. |
| **`Alt + 3`** (или **`Alt + C`**) | `F6` | **Чей ход** | Моментальное переключение очереди (Белые ↔ Чёрные). |
| **`Alt + 4`** (или **`Alt + V`**) | `F7` | **Мои фигуры** | Переключение стороны игры (Белые ↔ Чёрные). |
| **`Alt + 5`** (или **`Alt + B`**) | `F2` | **Скрыть / Показать оверлей** | Включение/отключение отображения стрелок на экране. |
| **`Alt + 6`** (или **`Alt + S`**) | `F3` | **Пересчёт** | Принудительный анализ текущего кадра доски. |
| **`Esc`** | `Esc` | **«Кнопка паники»** | Мгновенно скрывает оверлей с экрана. |

## 🚀 Установка и запуск

### 1. Требования
* Windows 10 / 11 (64-bit)
* Python 3.10+
* Установленный Stockfish (файл `stockfish.exe` уже включён в репозиторий)

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

*Содержимое `requirements.txt`:*
```text
numpy>=1.24.0
opencv-python>=4.8.0
Pillow>=9.5.0
mss>=9.0.1
pyautogui>=0.9.54
pywin32>=306
```

### 3. Запуск
```bat
start.bat
```
*(или `python run.py` в терминале)*

## 🎮 Быстрый старт

1. Откройте любую шахматную партию в браузере (Chess.com, Lichess и т.д.).
2. Запустите `start.bat`.
3. Если игра на втором мониторе — выберите нужный экран в поле **«Монитор»**.
4. Нажмите **«Выделить область»** и обведите доску 8x8 рамкой. Бот автоматически привяжет координаты ровно к клеткам.
5. Нажмите кнопку **«Сетка»** для визуальной проверки.
6. Выберите нужный режим:
   * Хотите играть руками по стрелкам $\to$ оверлей прозрачен и клик-проходим.
   * Хотите играть со скрытыми стрелками $\to$ выберите **«Без стрелок»** и включите **«Озвучка: ВКЛ»** (ходы будут произноситься в наушники).
   * Хотите включить автоход $\to$ нажмите **«Автоход: ВКЛ»** (по умолчанию мышь будет брать и перетаскивать фигуры как человек).

## 📂 Структура проекта

```text
chess4-screen-bot/
├── chessvision/
│   ├── app.py            # Графический интерфейс Tkinter и клик-проходимый оверлей
│   ├── board.py          # Логика шахматной доски, генератор ходов, FEN, валидатор позиций
│   ├── engine.py         # UCI-клиент Stockfish (MultiPV, Elo limit, авто-восстановление пайпа)
│   ├── mouse.py          # Человеческая кинематика мыши (сплайны Безье, Flash-Hogan, Drag & Drop)
│   ├── templates.py      # Классификатор фигур по силуэтам (Neo, Staunton) и геометрии
│   ├── vision.py         # Захват экрана (mss), поиск доски (Hough/Canny), чтение клеток
│   └── voice.py          # Локальный синтез речи Windows SAPI (Microsoft Irina, русский SAN)
├── stockfish/            # Движок Stockfish 19 Universal
├── tests/                # Набор модульных тестов
│   ├── test_app.py
│   ├── test_board.py
│   ├── test_hotkeys_and_hidden_arrows.py
│   ├── test_stealth_multipv_voice.py
│   └── test_user_scenarios.py
├── config.json           # Сохранённые настройки пользователя
├── requirements.txt      # Python-зависимости
├── run.py                # Точка входа Python
└── start.bat             # Быстрый запуск в один клик
```
